# 联网验证器验收记录

日期：2026-11-09。基于GitHub `6fe2c8f` 的隔离工作树。用户要求每条预测独立搜索、判断并返回，并进一步要求程序内完成复核和修正，不依赖聊天主代理逐条裁定。

## 最终行为

一次调用可选择单条、明确ID列表、当前未定项或全部预测。任务内部完成：规划 → 双向搜索 → 读取正文 → 初判 → 独立LLM请求复核 → 必要时修正一次 → 再复核。复核仍不通过则自动返回具体未定；API或结构失败单列为技术状态。

默认8条并发，最多两轮搜索和8次LLM调用；逐条完成即回调、落盘，最终生成JSONL、统计和可读报告。初始设计的5次模型调用上限在用户追加自主判断要求后改为8次；原两条试跑的总预算仍为LLM 1元、Exa 0.10美元。

## 本地验证

完整117项本地测试通过，其中工作流35项、语义复核20项。测试涵盖实际线程重叠、一次修正后接受、持续失败自动未定、上下文与引用范围、日期、原文不变、预算竞争、失败隔离、402/429、恢复和篡改拒绝。PDF仅允许唯一空白对齐；数字、词语、标点和歧义变化仍拒绝。

LLM缓存检查原始响应SHA256及解析JSON一致性；缺乏完整性凭据的旧缓存标为legacy_unverified并拒绝自动使用。失败、无用量和未知请求保留预算，不伪装成免费。旧账本中的成功无用量保守估价兼容保留，并明确标识未知。

《美国反对美国》135条候选/123条证据、《李光耀观天下》326条候选/216条证据检查通过；报告重建后案例目录差异为0。本次没有修改已发布的书籍判断。

两条固定任务为教育危机条件判断（txt-1c4066fc0c-000188277-000188300）与布鲁金斯成果后用（txt-1c4066fc0c-000208790-000208831）。没有运行整本书或原43条复核。

|---|---:|---:|---|

针对教育复核的结构问题，程序只允许“结论逻辑”和“时间逻辑”的问题引用草稿，并标明quote_origin=proposal；对象、条件、证据和反证问题仍必须引用原书或真实来源。草稿不作为外部事实证据。提示词同时明确区分条件A与后果B：前提指标部分改善，不自动证明后果只实现一部分。

最终自主阶段复用冻结的搜索材料及已成功初判请求，只新增复核和修正的真实LLM调用，Exa网络禁用。因此它不是重新搜索后偶然换了一组有利材料；也不能称为所有步骤再次联网。所有阶段、错误、累计费用和摘要哈希均保留在[试跑收据](validation/search-verifier-smoke.json)。原始请求、响应和正文提取件在本地忽略目录，未上传完整原书或密钥。

## 适用边界

程序现在可以自行产生有界判断、修正或具体未定，没有人工逐条审核的运行前提。独立抽查可以用于衡量整体质量，但不参与每个任务的执行链。

复核使用同一模型的不同请求与不同提示词，仍可能存在相关错误；这两条是开发回归样本，不是独立盲测，也不能证明跨书预测判断的准确率。元数据日期不全、旧来源只有年/月精度、上下文截断以及原文对象模糊仍可能使程序保守地返回未定。程序内复核是可审计的决策步骤，不能包装成科学认证。
