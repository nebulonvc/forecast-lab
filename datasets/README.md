# 核心汇总数据集说明与字段字典（`datasets/`）

本目录提供全库清洗、去重、对齐口径后的两张核心 CSV 数据总表，采用带 BOM 的 UTF-8 编码（`utf-8-sig`），既可直接用 **Excel / Numbers / 飞书表格** 双击打开不乱码，也可直接用 **Python (Pandas / DuckDB) / R / AI Agent** 进行统计建模。

---

## 1. 全案例统计总表：[`all_cases_summary.csv`](all_cases_summary.csv)

覆盖全库去重后的 **132 部独立著作**（合计 8,130 条可评分预测、5,060 条明确判定），包含跨度分档与同档超额指标，共 **37 列**：

| 字段分组 | 列名 | 说明与计算口径 |
| :--- | :--- | :--- |
| **基础元数据** | `slug` | 对应 [`cases/<slug>/`](../cases/) 下的唯一案例目录名 |
| | `领域` | 七大领域分类（地缘政治、宏观金融、科技商业、AI与奇点、人口能源生态、社会制度文化、科幻乌托邦） |
| | `作者类型` | 六类作者群体（国际机构与政府智库、政治家与战略实务者、地缘与社科学者、经济学家与投资人、科技商业实践者、古典与科幻作家） |
| | `作者` / `书名` | 作者或发布机构名称、作品标题 |
| **时间与口径** | `出版年` / `截止日` | 写作或初版代理年份、证据核验截止日期（ISO 格式） |
| | `观察窗口年数` | `截止年 - 出版年` |
| | `时间跨度分档` | 六档：`0–3年(超短窗)`、`4–9年(中短窗)`、`10–19年(中长窗)`、`20–39年(长周期)`、`40–99年(跨代)`、`≥100年(跨世纪)` |
| | `写明期限中位目标跨度年` | 书中明确写出到期年份的预测条目，其目标年份距出版年的中位数 |
| | `批次口径` | 入库与复核批次标签（详见 [`panoramic-report.md`](../docs/reports/panoramic-report.md) §1.1） |
| **五类核心计数** | `预测数` / `可判定数` | 可评分预测总数；`可判定数 = 预测数 - 暂无法判断` |
| | `正确` / `趋势符合` / `部分符合` / `错误` / `暂无法判断` | 五类互斥结论各自条数（`正确 + 趋势符合 + 部分符合 + 错误 = 可判定数`） |
| | `剔除非预测数` | 抽取阶段按格言、倡议、历史等规则剔除的非预测条数 |
| **核心比率** | `严格胜率` | `正确 / 可判定数` |
| | `方向命中率` | `(正确 + 趋势符合) / 可判定数` |
| | `错误率` / `未定率` | `错误 / 可判定数`；`暂无法判断 / 预测数` |
| | `展示加权分_20261116口径` | 历史辅助展示分 `(正确 + 0.75×趋势符合 + 0.5×部分符合) / 可判定数`，不替代主口径 |
| **期限硬度拆解** | `写明时间可判定数` / `严格胜率` / `错误率` | 原文显式给出时间窗口（`explicit`）子集的表现 |
| | `隐含窗口可判定数` / `严格胜率` / `错误率` | 原文未写死日期的方向判断（`implicit`）子集的表现 |
| **同档基准校准** | `同档基准严格胜率` / `方向命中率` / `错误率` | 该书所在`时间跨度分档`的全体同行平均水平 |
| | `同档超额严格胜率_pp` | `本书严格胜率 - 同档基准严格胜率`（正值代表跑赢同时间跨度同行，单位：百分点） |
| | `同档超额方向命中率_pp` | `本书方向命中率 - 同档基准方向命中率` |
| | `同档低错优势_pp` | `同档基准错误率 - 本书错误率`（正值代表比同档同行更少犯错） |

## 2. 精选 330 条预测总表：[`curated_330_forecasts.csv`](curated_330_forecasts.csv)

从全库 8,130 条预测中人工去重、严格互斥筛选出的 **330 条高含金量样本**（零 UID 重叠），共 **11 列**：

| 列名 | 说明 |
| :--- | :--- |
| `编号` | `H001`–`H100`（百大精彩预测）、`M01`–`M50`（五十高手翻车）、`F1-01`–`F6-30`（六大领域各 30 条未来方向，共 180 条） |
| `板块` | `A_百大精彩预测` / `B_五十高手翻车` / `C_未来方向罗盘` |
| `领域` | 所属核心领域 |
| `作者` / `书名` / `出版年` / `观察窗口年数` | 来源著作信息与历史检验跨度 |
| `预测命题` | 经消歧整理的核心可核验预测陈述 |
| `核验或前瞻摘要` | 客观历史核验事实（A/B 板块）或当前阶段进展摘要（C 板块） |
| `核心标签` | A 板块标**六大推理方法原型**；B 板块标**五大翻车死因**；C 板块标**未来演进状态** |
| `复盘启示或2026-2035跟踪指标` | B 板块给出防踩坑教训；C 板块给出 **2026–2035 具体领先观测指标** |

## 3. 预测方法优化模型与样本外交叉验证基准

- [`forecast_optimizer_model.json`](forecast_optimizer_model.json)：基于全库 132 部著作（8,130 条预测 + 2,553 条非预测 + $t_0$ 宏观历史状态）训练固化的对数线性池化超学习器（`SuperLearner`）参数包（含 SHA-256 完整性校验），供 [`toolkit/forecast_optimizer.py`](../toolkit/forecast_optimizer.py) 与 [`toolkit/forecast_mcp.py`](../toolkit/forecast_mcp.py) 零依赖毫秒级加载。
- [`optimization_benchmark.json`](optimization_benchmark.json)：按著作分组五折交叉验证（Out-of-Book 5-Fold Grouped CV）的 8 组学术模型对比指标（Brier、LogLoss、序数 RPS、ECE）及 Cochran-Mantel-Haenszel 分层因果效应表。详见 [`docs/06-forecast-method-optimization.md`](../docs/06-forecast-method-optimization.md)。
- [`historical_tech_diffusion_atlas.json`](historical_tech_diffusion_atlas.json)：跨越 1882–2025 年的 **12 次代表性技术浪潮扩散基线与四层摩擦参数表**（基于 Comin-Hobijn NBER CHAT、Bass 1969 S 曲线系数 $(p, q)$、Paul David 发电机悖论及本库 132 部著作实证锚点），记录增量 `5%→50%` 耗时、存量更替耗时、资产周转底线与当下实时瓶颈核查清单，用于定量检验新技术“这次是否不一样”。

## 4. 快速 Python 查询示例（仅需标准库 `csv`）

在仓库根目录直接运行以下命令，即可筛选“检验跨度 10–39 年、可判定 ≥ 30 条且同档超额严格胜率最高的前 10 部作品”：

```bash
python3 -c '
import csv
with open("datasets/all_cases_summary.csv", encoding="utf-8-sig") as f:
    rows = [
        r for r in csv.DictReader(f)
        if r["时间跨度分档"].startswith(("10–19", "20–39")) and int(r["可判定数"]) >= 30
    ]
rows.sort(key=lambda r: float(r["同档超额严格胜率_pp"].replace("pp", "")), reverse=True)
for r in rows[:10]:
    print(f"{r[\"书名\"]:22s} ({r[\"出版年\"]}) | 严格:{r[\"严格胜率\"]:>6s} | 同档超额:{r[\"同档超额严格胜率_pp\"]:>7s} | 错误率:{r[\"错误率\"]:>5s}")
'
```
