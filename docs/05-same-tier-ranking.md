## 指标说明

| 指标 | 计算方式 | 含义 |
| :--- | :--- | :--- |
| 严格胜率超额 | 本书严格胜率 − 同档平均严格胜率 | 完全兑现的比例比同龄作品高多少 |
| 方向命中率超额 | 本书方向命中率 − 同档平均方向命中率 | 方向判断（正确 + 趋势符合）比同龄作品准多少 |
| 低错优势 | 同档平均错误率 − 本书错误率 | 出错比例比同龄作品低多少 |
| **综合超额** | 上述三项的算术平均（百分点） | 排序依据；正值表示总体跑赢同档基准 |

同档基准按六个时间跨度档分别计算：0–3 年、4–9 年、10–19 年、20–39 年、40–99 年、100 年以上。三项指标单独排序的结果可能不同，表中三列均已列出，便于按需重排。

**类型标签**（与同档相差在 ±1.5 个百分点内视为持平）：全面领先（三项均不低于同档，且至少两项领先）· 准且稳（严格胜率领先，错误率不高于同档）· 高命中·高波动（严格胜率领先，但错误率高于同档）· 方向型（方向命中率领先，严格胜率不高于同档）· 谨慎少错（仅错误率低于同档）· 全面落后（三项均不高于同档，且至少两项落后）· 偏弱（其他）。
