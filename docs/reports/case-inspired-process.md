# 案例启发的预测流程：从判断到可复盘承诺

记录直接显示，这些作者会使用历史经验、制度结构、能力约束、趋势外推与条件分支；合理但尚未证实的推断是，他们的某些优势来自抓住行动者真正受制约的环节；目前不能证明某一类信息源或“慢变量”本身带来高准确率。最值得采用的是让每个因素有来源、每段因果链有反例、每条预测有边界。

这是一套**案例启发的规范流程，尚未经前瞻验证**。我们比较的是有边界的预测承诺，不给作者贴“先知／失败者”标签；原判定只作原记录标签，机制是否成立另说。下文P编号对应附录，所有方法比较、流程动作均为本次推断或建议，除非特别注明作者原话。

## 一页用法

**先定题 → 选关键因素 → 检验机制 → 定变化速度 → 接到触发与行动 → 写不确定分支。**

每次输出一张预测卡、一张因果分支表和一个更新日期。先找可比案例的基准率，再提出为何偏离；没有可比样本，明确写“基准率未知”。对未来自己可结算的预测，优先登记可校准、可更新的数字概率或区间；缺信息时不强填概率，不用确定语气弥补数据缺失。

开始前冻结：原话和版本、当时信息截止、结果定义、对象范围、期限与判据。检索对照时纳入失败和未定，但不把未定当成功，不把相似case当独立试验。没有观测到机制，不妨碍先记录事件；也不允许以事件补齐机制。

## 第一步：先定义结果，再选因素

**要回答：谁在什么范围内，到何时，做到什么才算发生？**

把一个大判断写成“主体＋对象＋量词＋指标＋期限＋条件”。对象是单产品、后继产品族还是产业？“出现／普及／主导／取代”分别立判据；“尝试推动／获得能力／实施行动／达成结果”不要混。拆开复合承诺，但保留父条目与相关组，不拆成独立命中次数。

- **典型对照P02：** 克里斯坦森《创新者的窘境》说电动车构成未来威胁，原正确；说初期获胜设计是简单便利，原错误。领域方向、产品形态与进入路径不是一个答案。
- **反偷换对照P04：** 安吉尔《大幻觉》跨国合作增加原正确，支配竞争停止原错误。“增加”不等“取代”。

**本步交付：** 一句可判的承诺＋不包括什么。无法写清判据的，先作为观察问题，不包装成可计分预测。

## 第二步：围绕动机、能力、约束选因素

**要回答：谁想做、谁能做、谁决定，谁受益又由谁买单？**

列出三至五项最可能改变结论的因素，注明来源是当时数据、制度、历史、访谈还是假设；问“拿掉它，结论会变吗？”几乎不变的只是背景。经济上重要不等于有否决权；全社会不划算也不等某集团没有短期收益。把决策权、资源控制、代价承担和绕行能力放到同一张表。

- **典型对照P01：** 作者明确用“价值网框架”解释磁盘企业难在闪存领先，原正确；同框架推电动车新市场几乎必把弱点当优点，原错误。框架能提示约束，不能唯一推出路径。
- **跨环境对照P35：** Graddol《英语的未来？》迁移使粤吴语扩张原错误，印尼语扩张原正确。迁移规模之外，还应检查政策和协调网络；这是本次提出的中介假设，不是已识别的跨国因果效应。

**本步交付：** 行动者表：目标／决策权／可用能力／约束／受益与买单者／可绕行方式。

## 第三步：检验重要性，而不只找同时出现

**要回答：因素通过哪个可观察中介改变结果？还有谁能造成同样表象？**

画“因素A → 中介M → 行动或反应R → 结果B”。每个箭头注明依据、替代解释、断裂条件，以及如果为真应先看到什么。历史类比同时列相似和差异，特别是力量、制度与外部环境；有可比数据时比较统计关系，但相关不等于因果；没有数据也应明确机制假设，没有对照不能把合理故事写成因果识别。

- **典型对照P60：** 凯恩斯《和平的经济后果》俄国出口恢复慢原正确，1920—21年小麦必稀贵原错误。局部供给迟缓到全球价格之间，还有其他产区、丰歉与替代；原句另有丰收例外，不能跳过。
- **技术到结果P71：** 《AI 2041》中李开复分析章（陈楸帆故事未计预测）关于AI重塑医疗原正确，显著加速并降低药物发现成本等复合结果原部分符合。蛋白结构、候选分子、临床获批、支付和患者收益不是同一阶段。

**本步交付：** 至少一条主机制、一条替代路径与一个领先指标。只有B有证据时，事件可更新，机制保持待查。

## 第四步：快慢必须相对于期限来定

**要回答：什么能在本次窗口内变，速度由什么限制，何时变轨？**

把存量、流量、单位、分母、起点和速率分开。同一因素对三个月很慢，对二十年可能已大变。人口有代际滞后、合同有到期日、设施有建设周期，制度也会突变；地理位置不变，技术仍可改变其价值。**重要不等于慢，慢不等于不变，更不等于更准。**

- **典型对照P09：** 安德森《免费》中国网游2010年规模门槛原正确，所有数字化事物边际成本每年减半原错误。数字不是原罪，固定普遍速率也不因方向对而成立；旧证据又有价格代理成本的限制。
- **门槛与类比P16：** 戴维《航空器》纽约—芝加哥3美分邮资原正确，大飞机像高档汽车般便宜原错误。先锁收费／成本、机型和比较对象，不凭类比给速率。

**本步交付：** 速率卡：现有存量／净增减来源／速率与单位／时滞／期限／变轨条件。区分点值、阈值、区间、累计量和逐年增长率；“截至某年”不是“恰在某年”。

## 第五步：把慢条件、快触发和行动接起来

**要回答：结构约束怎样经由一个触发，改变某人的行动？其他人会如何反应？**

用分支表连接约束→触发→谁行动→中介→结果，再加替代供给、政策响应与反馈。让行动更贵、使其不太可能、使其物理上做不到，是三个强度。低成本可能引发更多使用，局部节约不自动降低总需求。人口优势也要经过就业、生产率、资本和需求才能变成增长；政权依赖军队，还要问何种事件改变军队的利益、团结与资源。这两项是承接原稿的规范检查，不在本材料中宣称已有因果验证。

- **典型对照P54：** IEA《全球关键矿产展望2024》钴价2024年低迷原正确，近期难获价格支撑原部分符合；2025年出口限制改变了供给边际。产能是条件，政策决定可流通量，但“近期”原窗未锁死。
- **路径与功能P77：** 马汉《美国海权的利益》尼加拉瓜运河路线原错误，不论路线都会形成贸易枢纽原正确。同一功能可经不同路径实现，路径错不能抹掉功能，也不能反过来救路径。
- **反直觉反馈P49：** IEA《能源与人工智能》模型效率改善与便宜后更多使用／更多算力，两条均原正确。它们不矛盾；但价格、支出与资本开支不是焦耳和实际算力，不足独立证明净能耗反弹因果。

**本步交付：** 两条以上可区分的行动分支、各自触发与改判信号。没有事实支持的反馈边，只作待检假设。

## 第六步：写清不确定分支，而不是加一句“可能”

**要回答：A是否会来？若A发生，B多大可能？什么观察会改变判断？**

条件独立记三笔：A的发生状态与证据；A内B的结果；作者是否还承诺A本身很可能发生。必要条件“只有A才B”不是“A即充分导致B”；“A或B”不是两者都要；“所有／永远不再”比“有些／一次出现”强。不能把结果B塞回A，构成“足以造成B的A未出现，所以不能判错”的循环。

- **典型对照P22：** 埃利希《人口爆炸》“无论现在采取什么紧急计划，1970年代仍有亿级饿死”原错误；趋势延续前提下1984美国缺水原未定。前者已排除干预借口，不能事后一律说“因为预警而避免”；后者也不因危机未发生就变正确。
- **能力上界P05：** 亚当斯《亨利·亚当斯的教育》复杂性增加原正确，1950年人类轨道如流星般精确可算原错误。趋势延续不自动推出预测精度、无限上界或精确终局。

**本步交付：** 分支、概率或诚实的定性区间、基准率、观察窗口、更新条件。不给历史作者补造数字概率；单次低概率事件发生，不足独立裁定其概率失准。远期负事件未到期、前提未触发、缺证据、无终判与非预测分别列账。

## 更新与复盘：三轴主账，记录质量另列

| 轴 | 要核什么 | 不允许的偷换 |
|---|---|---|
| 事件 | 原定义的对象、数量和范围是否出现 | 原型→系统，采用→净收益，行动→成果，威胁→灾难已经发生 |
| 机制 | 中介、行动者响应和替代路径是否有证据 | 结果发生→理由必对；只知道B就认定A已满足 |
| 时间 | 是否原窗内、是否持续、是否首次交点 | 提前达门槛算错；逾期才成算按时；未到期未发生算成功 |
| 记录质量（独立） | 版本、归属、量词、证据、原评代理是否一致 | 评分漏洞算作者失误；报告和复用来源当独立互证 |

每次更新检查：①新观察到底改变哪一格？②是否同任务、同单位、同分母？③有没有相反证据或替代机制？④应调整分支权重、触发行动，还是只记录缺口？⑤原话、旧判断和改动原因是否保留？

复盘先比**同题不同路径、同方法不同结局**。按事件簇归并相关条目作敏感性检查，不将一场战争或同一产业史重复计数。若将来要验证本流程是否更好，应事前登记、找可比题组并做前瞻检验；本次材料没有提供这种因果结论。

## 将流程走一遍：运河功能不等于工程路线（P77）

以下是本次回看记录后的示范，不冒充马汉当年的预测卡，也不补造当时概率。

1. **定题：** 把“将选尼加拉瓜路线”和“不论路线，运河将成贸易枢纽”列为两个承诺；不因同段文字合并成一次全中或全错。
2. **因素：** 分清海上贸易需求与路线的工程、融资和政治决策；后几项在现摘录没有充分依据，填写“待查”，不能假设作者已评估。
3. **机制：** 前者须解释谁决定路线、什么会改选；后者须解释航线汇聚如何形成枢纽，并保留替代港口／航线分支。这是建议的检验，不是现有因果识别。
4. **时间：** 原引文没有明确落成期限，不新增作者承诺；若自己重做，应事前给出期限或触发式复查，并定义枢纽门槛。
5. **更新：** 路线决定可以只更新工程路径，不自动否定功能；航量证据只能更新功能，不能拯救错误路线。
6. **复盘：** 原记录路线错误、功能正确；事件分开记，机制证据不足处留缺口，时间不事后补写。共用同一运河事实簇，不计两次独立验证。

## 本次真正强化的八点

1. **从因素清单到可判承诺：** 先冻结对象、量词、连接词、指标与边界。
2. **从国家／企业意志到决策结构：** 加入谁有权、谁受益、谁付成本及能否绕行。
3. **从故事合理到箭头可检：** 中介、替代解释、反证与领先指标逐边记录。
4. **从慢变量标签到速率卡：** 相对期限，分存量流量、时滞、单位、分母与变轨条件。
5. **从静态约束到响应网络：** 接快触发、替代供给、制度改变、反弹和反馈。
6. **从模糊可能到独立分支：** 条件A、P(B|A)与A本身的概率分开；拒绝循环前提。
7. **从赢家故事到基准率对照：** 纳入失败、未定与相关簇；不知道的基准率不伪造。
8. **从单一命中率到事件／机制／时间三轴：** 原评分与记录缺陷另列，保存可追溯更新。

**两点尤其反直觉：** 精确数字有命中，宽泛方向也会失败，不能以“少说数字”替代正确操作化（P09、P16）；效率提高与总需求增加可以同时发生，局部进步不必减少系统消耗（P49）。再如，同一作者能预警战争又误判群体不会参战，作者标签不替代逐条阅读。
