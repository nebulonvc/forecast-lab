## 一、找书与选本防穿越三条铁律（必读）

按本库 [`METHOD.md`](reference/METHOD.md) 的防信息穿越与口径冻结规则，找书与挑选底本时请务必遵守以下三条铁律：

1. **铁律 1：只下“战时 / 在任实时发表的政论、演说、奏议与电报”，慎下“晚年事后回忆录”**
   - 本库以 `publication_year_proxy` 锚定预测发布时点 $t_0$。回忆录中回顾早年局势的判断在成书时已属于 `historical`（过去历史），会被管线自动剔除。
   - 若使用晚年回忆录（如俾斯麦《思考与回忆》），仅抽取针对**成书年份之后**的未来预言；丘吉尔、戴高乐等人则优先下载**二战爆发前已公开出版的实时演说集与政论**。
2. **铁律 2：只下“针对具体大局的形势推演”，不下“抽象兵法与纯规范哲学原理”**
   - 如《孙子兵法》、克劳塞维茨《战争论》等经典军事哲学，绝大部分篇幅属于静态规律（`mechanism`）或格言（`aphorism`），可结算预测密度极低。
3. **铁律 3：多篇文集必须“按单篇真实写作年独立锁死 $t_0$”，且优先下载“当年初版原貌底本”**
   - 例如毛泽东著作优先对照 1938 年延安解放社单行本或竹内实编《毛泽东集》原貌本，按单篇真实写作年份独立建库，严禁混用 1950 年代选集出版年。

```bash
python3 toolkit/contribute_book.py init \
  --case cases/<上表建议的 case_slug> \
  --book "<书名>" \
  --author "<作者>" \
  --publication-year <锁定 t0> \
  --domain "<七大标准领域之一>" \
  --author-type "<六大标准作者类型之一>"

# cp /path/to/book.txt cases/<case_slug>/input/book.txt
```
