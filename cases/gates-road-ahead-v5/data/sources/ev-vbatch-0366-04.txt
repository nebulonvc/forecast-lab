IBM Smart Surveillance System (S3): A open and extensible framework for event based surveillance for AVSS 2005 - IBM Research AVSS 2005 Conference paper 01 Dec 2005 IBM Smart Surveillance System (S3): A open and extensible framework for event based surveillance View publication Abstract As Smart Surveillance technology becomes a critical component in security infrastructures, the system architecture assumes a critical importance. This paper considers the example of smart surveillance in an airport environment. We start with a threat model for airports and use this to derive the security requirements. These requirements are used to motivate an open-standards based architecture for surveillance. We discuss the critical aspects of this architecture and its implementation in the IBM S3 smart surveillance system. Demo results from a pilot deployment in Hawthorne, NY are presented. © 2005 IEEE.
