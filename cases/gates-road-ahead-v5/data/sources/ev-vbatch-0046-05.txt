Guides: Magic Remote | webOS TV Developer. The LG Smart TV is boxed with one of the two following remote control units: Magic Remote Control Unit allows for free pointing and clicking, as well as standard 5-way controls. AI(Voice) input and universal remote functionality are also provided. Conventional Remote Control Unit allows for standard 5-way controls, with additional physical keys as shortcuts to commonly used actions. Action Description: OK : Select an on-screen UI element. Back : Returns to the previous page or the system Home. As described at the top of this article, remote controls have two navigation modes, pointer, and 5-way modes. Pointer mode : The remote control works similarly to a mouse (or, we prefer to refer to a wand). You can point or select items, or scroll up or down using the wheel.
