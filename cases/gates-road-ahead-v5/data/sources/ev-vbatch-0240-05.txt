Canvas Portfolio: Create, Share, and Assess Student Work
Tags Canvas LMS portfolio course assignment learning digital assigments folio
Canvas Portfolio is available now. Faculty can use it to guide portfolio-based learning and assessment, while students and faculty can create portfolios that showcase work from courses and experiences beyond the classroom.
Canvas Portfolio is a portfolio tool built into Canvas. It brings together course assignments, uploaded work, reflections, and other evidence so learners can document their growth, demonstrate competencies, and share selected accomplishments.
Moving from Portfolium? Canvas Portfolio is the successor to Portfolium (also called Canvas Folio) and Canvas’s legacy ePortfolio tools. If you previously used Portfolium, refer to the emails Instructure sent about your migration options. Those messages contain information specific to moving or preserving your existing content.
Two types of portfolios
Comparison of Showcase and Evaluation Portfolios Portfolio type Best for How it works
Showcase Portfolio Presenting selected academic, co-curricular, or professional work The portfolio owner chooses the evidence, organization, reflections, and tags. A Showcase Portfolio is private by default and can later be shared through a public link or LinkedIn, or exported as PDF, HTML, or a collection of files.
Evaluation Portfolio Instructor-guided reflection, assessment, and demonstration of competencies An instructor creates requirements connected to one or more Canvas courses. Enrolled students are assigned the portfolio and submit the requested evidence. Instructors can monitor progress and review evidence as Complete or Not Complete. Canvas assignments included as requirements can still be graded in SpeedGrader.
Open Canvas Portfolio
Sign in to Canvas .
Select Account in the global navigation.
Select Portfolio .
A Portfolio link may also appear in a course’s navigation menu. The Account menu provides access to all of your portfolios, regardless of course.
Faculty: Get started with an Evaluation Portfolio
Open Account > Portfolio .
Select Create portfolio , and then select Create evaluation portfolio .
Select one or more Canvas courses. Students enrolled in the selected courses will be assigned the portfolio automatically.
Add a name, instructions, and an optional cover image.
Add evidence requirements. A requirement can use an existing Canvas assignment or ask students to provide other evidence.
Organize requirements into sections as needed.
Save the portfolio as a draft and review it carefully before publishing.
Publish the portfolio and tell students what they need to complete and when.
Review before publishing: A published Evaluation Portfolio cannot currently be edited. Portfolio also does not currently send email or in-app notifications, so communicate expectations and changes to students through your usual Canvas course channels.
For screenshots and complete instructions, see How do I create an Evaluation Portfolio as an instructor?
Faculty: Create a Showcase Portfolio
Faculty can also create Showcase Portfolios. These can be useful for sharing an example with students, presenting professional work, or modeling the selection and reflection process you expect students to follow.
Open Account > Portfolio .
Select Create portfolio , and then select Create showcase portfolio .
Add portfolio details, evidence, reflections, and sections.
Save a draft or publish the portfolio when it is ready.
If you want others to see it, use the portfolio’s sharing options to create a link.
See How do I create a Showcase Portfolio as an instructor?
