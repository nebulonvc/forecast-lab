Access | Wi-Fi Alliance Skip to main content Access Wi-Fi Alliance® has a range of technologies that offer standardized mechanisms for adding, authorizing, and authenticating Wi-Fi® devices onto a wireless network with greater simplicity. Wi-Fi® access technologies Passpoint® Wi-Fi Easy Connect™ Wi-Fi Protected Setup™ Unsynchronized Service Discovery Passpoint® Passpoint® streamlines Wi-Fi access, eliminating the need for users to find and authenticate to a network each time they visit. Passpoint automates the entire process of network authentication, enabling more seamless Wi-Fi connectivity between Wi-Fi networks and mobile devices. Passpoint offers the following features to enhance the mobile experience: Automatic network discovery and selection Seamless network access and roaming between hotspots Enhanced WPA3™ security View all resources Wi-Fi Easy Connect™ Wi-Fi Easy Connect™ provides standardized mechanisms to simplify the provisioning and configuration of Wi-Fi devices. Provisioning and configuring devices, including those without a rich user interface, is as simple as scanning a product quick response (QR) code, NFC tag, or downloading device information from the cloud to enable zero-touch Wi-Fi connectivity. Wi-Fi Easy Connect offers the following features: A standardized, consistent method for onboarding devices Improved network management through reconfiguration and support for multiple configurators Public key cryptography for secure authentication Maintains device connections to the network even if there are changes to the network, such as a new SSID Enables the replacement of access points (APs) without the need to re-enroll all devices to the new AP View all resources Wi-Fi Protected Setup™ Wi-Fi Protected Setup™ is designed to ease the setup of security-protected Wi-Fi networks in home and small office environments and supports methods that are familiar to most users to configure a network and enable security. Wi-Fi Protected Setup offers the following benefits: Industry-standard security features Easier approach for users to set up a security-protected Wi-Fi connection Additional devices can easily be added to a Wi-Fi Protected Setup network over time Available for a wide variety of product types and brands View all resources Unsynchronized Service Discovery Unsynchronized service discovery (USD) simplifies onboarding of Internet of Things (IoT) devices, benefiting Matter-capable devices. USD is also used in the Wi-Fi Aware™ and Wi-Fi Direct® protocols.
