Microsoft Copilot Chat and Microsoft Copilot responses and experiences differ by data grounding, integration depth, and licensing.
However, all experiences are powered by:
Large language models (LLMs) for natural language understanding and generation
Grounding in web and/or organizational data ( Microsoft Graph and Work IQ )
Access scoped by user permissions (security and compliance enforced)
Note
The Home tab provides a unified starting point for Chat and Cowork in the Copilot app. Users can switch between experiences from either the left navigation or the prompt box. Access to Cowork and Code capabilities depends on licensing , and assigned usage-based billing policy . If a usage-based experience requires a spending policy, the user is prompted to either Request access or Learn more , based on the organization's Access requests to usage-based billing policy .
