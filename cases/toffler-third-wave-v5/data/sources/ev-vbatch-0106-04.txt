Octoverse: AI leads Python to top language as the number of global developers surges (GitHub Staff, October 29, 2024; updated October 28, 2025). In this year’s Octoverse report, we study how public and open source activity on GitHub shows how AI is expanding as the global developer community surges in size. At the same time, we're seeing an unprecedented number of developers join GitHub from across the globe, and many of these developers are contributing to open source projects for the first time. In the past year, more developers joined GitHub and engaged with open source and public projects (in some cases, empowered by AI). And since tools like GitHub Copilot started going mainstream in early 2023, the number of developers on GitHub has rapidly grown with significant gains in the global south.
