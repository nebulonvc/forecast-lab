## 本轮结果

213条候选全部经过模型评估及原生Codex语义复核，保留122条预测，排除84条非预测和7条重复。122条均为暂无法判断；正确、趋势符合、部分符合、错误均为0。未决不是错误，也不能据此计算作者准确率。

未决原因：证据不足27、条件未确认48、定义不足33、归属4、观察范围不足2、未来期限8。当前22份证据不足以验证这些完整命题；这不是作者没有提出有价值判断或方法没有预测能力的证明。逐条报告保留已观察事实与缺口。

例如：特斯拉2019交付增长不直接证明相对竞争领先扩大或从2014起增速从未放缓；客服AI增效不验证未来最有价值产业的排名；基金期限与投资退出时间不同；PayPal后续现金流不直接验证2014估值中2020后现值占比。

## 抽取与复核来源

- DeepSeek首轮27次全文抽取返回214条建议；原始只有1段直接通过严格校验，其余26段拒绝。原答复完整保留，未默默重发。
- 本地LLM复核后恢复唯一原文换行、核对来自已给上下文的边界引文，并明确记录两处字词修正、空条件和未决标记修复。去掉10条完全相同位置后为204候选。详见 `output/txt_import/source_restore_audit.json` 与 `local_acceptance.json`。
- 独立的原生全书阅读形成34条参考，发现9处API首轮未覆盖的原文判断，补入后共213条。原生参考不是金标准，全文处理不证明零漏抽。
- 优化评估94次调用全部返回，179条当时通过结构校验，9批内34条被拒绝；原生LLM对213条全部阅读与修订后再校验导入，147条有修订、66条接受。修订包含方法字段恢复、日期/分类与实质证据对应，不能把147全称为事实错误数。
- 所有213条最终评估和22份来源存档哈希均通过程序校验。来源含完整下载与明确标记的搜索/工具摘录，哈希只证明内容未变。没有独立人类审阅。

## 速度与费用

- 首次生产抽取：12并发、27请求、19.60秒；优化评估：20并发、94请求、20.74秒。合计生产API约40.34秒，不含搜证、修复和复核。
- 带开发、调试、失败尝试和并发对照的记录时段约12.0分钟，从首次实验审计时间到报告生成；前置目录/代码检查未包含，不能当稳态单书SLA。
- 同书一次20并发请求对照为13.66秒，对比12并发19.60秒仅代表原始API响应；供应商缓存命中不同且校验失败，不能宣称整书提速30%已验收。预算仅¥1的另一次对照只发出10请求，已保留，不纳入完整对照。
- 同一冻结候选/证据/研究意见离线打包：上下文共享关闭193批、4,167,596字节；开启94批、2,175,715字节。批次减少51.3%，请求体减少47.8%；这是机械对照，不是质量证明。
- 全部实验（含失败/废弃对照）实际246次DeepSeek调用、1,310,032 tokens；按现有峰谷费率配置估计¥1.5103—¥3.0206，不是供应商账单。Codex和搜索费用未知，未写成零；每次请求与失败均在各运行目录账本中。

## 复用

```sh
python3 toolkit/pipeline.py --case cases/zero-to-one check
python3 toolkit/pipeline.py --case cases/zero-to-one report
```

新书可用 `prepare_book.py txt` 后接 `run_parallel.py --assess-only --share-contexts`。TXT检查点可供Codex提前组织搜证；搜证与逐条语义复核仍由Codex调度。本轮实验没有实现脱离Codex的独立无人值守CLI，也没有做相同范围的完整端到端基线对照。

原书、请求包和原始答复含原文，保留本地。密钥在仓库外，未写入案例或报告。当前案例是本地实验产物，未推送GitHub。
