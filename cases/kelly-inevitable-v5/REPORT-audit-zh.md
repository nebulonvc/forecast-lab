## 5. 代表例子

**正确**
- 几年后能用人工智能随意搜索视频：Google Cloud Video Intelligence API 2017年上线，可按物体检索镜头。
- 谷歌将把云端人工智能用于我们的文字：Smart Compose（2019）、Docs 生成式写作（2023 起）。
- 推荐过滤将扩展到优步、Airbnb 这类平台：两家都已部署个性化排序和推荐。
- 几年后人类数据量将达到泽字节级：IDC 估计2020年全球数据达 64.2ZB。
- 第一时间获得产品的即时性将成为可出售的原生性资产：超前点播和游戏抢先版收费普遍。

**错误（代表）**
- “到了2026年，谷歌的主营产品将不再是搜索而是人工智能”：FY2025 搜索收入仍占约56%。
- 5年后20TB硬盘售价60美元、可装进口袋：2021年20TB硬盘约650美元，且是3.5英寸盘。
- 预计到2025年地球上每个人都使用互联网：ITU 2025年上网率74%，约22亿人离线。
- 5年内联网设备达340亿台：2021年约110–120亿台。
- 电子书很快基本免费：代理定价后均价反而上升。
- 互联网巨头脆弱、短命、易被取代：十年间头部平台地位稳固。
